PROYECTO:
AVILES POS

OBJETIVO GENERAL:

Desarrollar desde cero una aplicación profesional de
punto de venta para tabletas Android.

La aplicación tendrá como referencia principal a
LOYVERSE POS.

Quiero reproducir lo más fielmente posible:

1. La distribución visual.
2. La experiencia de navegación.
3. El comportamiento de los botones.
4. La organización de productos.
5. El sistema de tickets.
6. La gestión de ventas.
7. Los módulos administrativos.
8. La facilidad de uso.
9. El funcionamiento táctil.
10. Las características funcionales del sistema.

IMPORTANTE:

La aplicación debe utilizar código original.

No copiar código fuente, logotipos, fotografías
protegidas ni otros recursos propietarios de Loyverse.

La referencia es su experiencia visual y funcional.

El resultado debe ser un producto independiente
llamado AVILES POS.

==================================================

en dos áreas principales.

Área de productos.

DERECHA:

Ticket de venta.

Proporción inicial aproximada:

70% productos.
30% ticket.

resolución real para garantizar legibilidad.

BARRA SUPERIOR:

Color verde similar al de las referencias.

Incluir:

- Botón de menú lateral.
- Nombre de categoría actual.
- Botón de búsqueda.
- Botón de escáner.
- Acceso a clientes.
- Menú de opciones.

ÁREA DE PRODUCTOS:

Mostrar productos en cuadrícula.

Cada producto puede incluir:

- Fotografía.
- Nombre.
- Precio.
- Categoría.
- Variantes disponibles.

Las tarjetas deben tener tamaños uniformes.

Las fotografías deben adaptarse sin deformarse.

BARRA INFERIOR:

Mostrar categorías.

Ejemplos:

Favoritos.
Bebidas.
Alimentos.
Postres.
Servicios.
Otros.

9. CARRITO Y VENTAS
==================================================

Al seleccionar un producto:

Agregarlo al ticket.

Si requiere modificadores:

Mostrar ventana de selección.

Si el producto ya existe en el ticket
con la misma configuración:

Incrementar cantidad.

Si tiene modificadores diferentes:

Mantener líneas separadas.

Permitir:

Cambiar cantidades.
Eliminar líneas.
Agregar notas.
Aplicar descuentos.
Cancelar operaciones.

Utilizar cálculos monetarios precisos.

No utilizar operaciones de punto flotante
sin control para calcular importes.

Efectivo.
Tarjeta.
Transferencia.
Otro.

Permitir:

- Pago con cambio.
- Pagos divididos.
- Pagos combinados.
- Descuentos.
- Impuestos configurables.
