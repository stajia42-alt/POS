# Dependencias y recursos

La interfaz, el icono de AVILES POS y la lógica comercial son propios de este proyecto. No se incorpora código, marca, logotipo ni fotografías de Loyverse. Las imágenes de referencia permanecen fuera del código entregado.

Dependencias directas incluidas en la aplicación:

| Paquete                    | Licencia declarada |
| -------------------------- | ------------------ |
| React y React DOM          | MIT                |
| Capacitor Core y Android   | MIT                |
| Capacitor Community SQLite | MIT                |
| sql.js                     | MIT                |
| Lucide React               | ISC                |

Los textos y avisos de licencia de cada dependencia se conservan en los paquetes instalados. SQL.js incluye SQLite; el plugin nativo incluye dependencias Android y SQLCipher con sus propios avisos. Antes de distribuir una versión comercial, conserva los avisos aplicables a la distribución final y revisa las licencias transitivas.

La aplicación admite fotografías proporcionadas por el usuario. El repositorio no incorpora un catálogo de fotografías comerciales. Las capturas generadas por E2E emplean dibujos originales realizados en canvas únicamente como entradas de prueba y no se precargan en el catálogo de la aplicación.
