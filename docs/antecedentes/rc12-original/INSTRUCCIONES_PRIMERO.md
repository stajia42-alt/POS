# Parking POS Desktop 1.0.2 RC3

**Abre primero `LEER_PRIMERO_RC3.md`.** Este ZIP contiene el proyecto de escritorio y los archivos para generar un instalador Windows x64, no el `.exe` ya construido.

Para construirlo en tu computadora: `CREAR_INSTALADOR_WINDOWS.cmd`. El nuevo instalador conserva los registros de `%LOCALAPPDATA%\ParkingPOS`. Haz un respaldo de esa carpeta antes de actualizar.
