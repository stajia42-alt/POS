AVILES POS 1.2 — INSTALACIÓN EN ANDROID

1. Abre AVILES-POS-1.2.apk en tu tableta Android.
2. Si Android lo solicita, permite instalar desde el navegador o la app Archivos.
3. Instala como actualización sobre AVILES POS anterior. No desinstales ni borres sus datos.
4. Abre AVILES POS. Crea al propietario con tu nombre, identificador y PIN propio. No hay PIN predeterminado.
5. Usa el menú: Productos, Inventario, Empleados y Caja y turnos.
6. Para caja: activa Control de caja por turnos en Configuración, guarda y abre un turno.

El APK conserva identificador y firma de desarrollo de las entregas 1.0 y 1.1. Si Android rechaza la actualización por firma, conserva la instalación con sus datos; no desinstales para forzarla.

Funciona offline y no requiere computadora ni servidor para operar. La carpeta AVILES-POS contiene código fuente, proyecto Android, migraciones, pruebas y documentación para desarrollo; no necesitas compilarla para instalar el APK incluido.

El APK es de depuración. Se compiló y verificó su firma; no se probó instalación o ejecución en una Galaxy Tab A11 física. No se declara terminado el sistema comercial de once fases. Faltan variantes, compuestos, devoluciones, puntos, impresoras, restaurantes, compras, reportes completos y respaldo/restauración. Lee AVILES-POS/AVILES_POS_PROGRESO.md y AVILES-POS/docs/MODULOS-1.2.md.
