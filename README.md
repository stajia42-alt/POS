# AVILES POS 1.1 — Instalador Android de pruebas

[Descargar APK para instalar](https://raw.githubusercontent.com/stajia42-alt/POS/instalador-aviles-pos-1-1/AVILES-POS-1.1.apk)

1. Descarga el APK desde el navegador de tu tableta Android.
2. Abre el archivo descargado. Si Android lo solicita, autoriza a ese navegador o gestor de archivos para instalar aplicaciones.
3. Pulsa Instalar y después Abrir. La aplicación se llama AVILES POS.
4. Desde el menú, configura tu negocio y registra categorías y productos. El catálogo empieza vacío.
5. En Punto de venta, agrega productos y pulsa COBRAR para registrar el pago. Tarjeta y transferencia se registran manualmente; no realizan un cargo bancario.

Es una compilación de depuración: la compilación, firma y recursos fueron verificados, pero todavía requiere pruebas físicas en la tableta. Si actualizas una instalación anterior, conserva la aplicación y sus datos; no desinstales ni borres almacenamiento. La 1.1 tiene el mismo identificador y certificado debug que la 1.0, con versionCode 2.

Esta rama distribuye únicamente el instalador solicitado. El código fuente está en la rama descargas-aviles-pos-1-1. No se distribuyen claves privadas de firma ni datos comerciales.
